gg / G         First / last log
Ctrl-d/u       Half page down / up
f              Toggle live follow
1/2/3/4        Toggle error / warn / info / debug
5              Toggle unclassified lines
0              Show all levels
h/l            Horizontal scroll
/              Edit filter (Enter applies)
Enter          Inspect / select / apply filter
a (tree)       Read all sources
Esc            Cancel filter / close detail
c              Clear query (levels stay)
q              Confirm quit / close detail

Filter editor: arrows move caret, Home/End jump,
Backspace/Delete erase. Esc discards edits.
Results change only when a valid query is submitted.

Inspector: / search, Enter finds, n/N next/previous.
y copies the entire record. Esc cancels search.

Filters (case-insensitive text or regex):
connection refused
~error|warn

JSON field queries (case-sensitive values):
json | level == "error"
json | http.status >= 500
json | message ~ "error" AND message ~ "500"
AND before OR; parentheses group conditions.

All indexed history retained; streams use temporary disk storage.
