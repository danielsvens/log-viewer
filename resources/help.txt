Navigation
  j/k or arrows     Move selection
  gg / G            First / last log
  Ctrl-d/u          Half page down / up
  h/l               Horizontal scroll
  f                 Toggle live follow
  Enter             Inspect log / select source
  q                 Confirm quit / close detail

Sources & tabs
  Tab               Focus sources / logs
  s                 Show / hide source tree
  a (tree)          Read all sources
  R                 Reconnect sources and refresh Kubernetes targets in this scope
  t                 New filter tab
  Shift-Left/Right  Previous / next tab
  x                 Close tab (keep one)

Filtering
  /                 Edit filter; Enter applies, Esc discards
  c                 Clear query (levels stay)
  1/2/3/4           Toggle error / warn / info / debug
  5                 Toggle unclassified lines
  0                 Show all levels

  Editor: arrows move caret, Home/End jump, Backspace/Delete erase.
  Results change only when a valid query is submitted.

Inspector
  /                 Search within the record; Enter finds
  n / N             Next / previous match
  y                 Copy the entire record
  Esc               Cancel search / close detail

Query examples
  connection refused
  ~error|warn
  json | level == "error"
  json | http.status >= 500
  json | message ~ "error" AND message ~ "500"

  Text and regex are case-insensitive; JSON values are case-sensitive.
  AND before OR; parentheses group conditions.

History & containers
  All indexed history is retained; streams use temporary disk storage.
  Container reconnect replays the configured tail; duplicates are possible.

Help: arrows / Page Up / Page Down scroll; q or Esc closes.

Kubernetes
  Deployment and pod rows select all their containers, including new replicas.
  Removed pods keep their history. Pending pods remain visible while waiting.
  Every regular container is included; init and ephemeral containers are excluded.
  Discovery runs every two seconds. Failed requests retry with backoff.
  R refreshes targets and retries disconnected readers in the selected scope.
  Restarts append to the same source. Replays may duplicate records; gaps are possible.
